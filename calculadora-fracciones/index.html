Calculadora de fracciones: sumar, restar, multiplicar y dividir

Escribe dos fracciones (por ejemplo 1/2 y 3/4, también números mixtos como 1 1/2 o decimales) y elige la operación. Te damos el resultado simplificado.

Compartir:WhatsApp

Cómo se opera con fracciones

Para sumar o restar se busca un denominador común: a/b + c/d = (a·d + c·b) / (b·d). Después se simplifica dividiendo arriba y abajo por el máximo común divisor.

Para multiplicar se multiplican numeradores y denominadores: a/b × c/d = (a·c) / (b·d).

Para dividir se multiplica por la fracción inversa: a/b ÷ c/d = (a·d) / (b·c).

Preguntas frecuentes

¿Cómo se simplifica una fracción?＋

Dividiendo el numerador y el denominador entre su máximo común divisor. 6/8 se simplifica a 3/4 dividiendo entre 2.

¿Qué es un número mixto?＋

Un entero más una fracción: 7/3 es 2 1/3, es decir, dos enteros y un tercio.
